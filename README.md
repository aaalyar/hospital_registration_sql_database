## Реляционная БД для регистратуры коммерческой больницы на MS SQL Server (T-SQL) с полным циклом бизнес-логики.

### О проекте

Проектирование и реализация базы данных для автоматизации работы коммерческой больницы:

- Учёт пациентов (поступление по отделениям, сроки пребывания, история болезни, привязка к лечащим врачам)
- Управление палатами
- Выставление счетов за пребывание и медицинские процедуры
- Ведение архива выписанных пациентов

### Структура БД

10 нормализованных таблиц (3NF):

- **Patient** – Пациенты (ФИО, дата рождения, пол, контактные данные, рост, вес, группа крови).
- **Department** – Отделения больницы (название, количество коек).
- **Doctors** – Врачи (ФИО, специализация, контакты, стаж, связь с отделением).
- **Wards** – Палаты (номер, отделение, пол пациентов, количество коек, занятость).
- **Admission** – Поступления (дата поступления/выписки, пациент, палата).
- **DiagnosisType** – Справочник диагнозов (название, описание).
- **MedicalHistory** – Медицинская история (дата лечения, план лечения, связь с поступлением, врачом, диагнозом).
- **ProceduresPrice** – Прейскурант процедур (название, описание, стоимость).
- **Procedures** – Выполненные процедуры (дата, связь с историей болезни и прейскурантом).
- **Bill** – Счета (дата, сумма, статус оплаты, срок платежа, связь с поступлением).

### Реализованный функционал (T-SQL)

В проекте используются продвинутые инструменты MS SQL Server:

**Представления (Views)**

- `FreeBedsInWardsByGender` – свободные места в палатах с учётом пола
- `PatientMedicalHistory` – полная история лечения пациента
- `PatientDischargeArchive` – архив выписанных пациентов
- `DoctorsAndPatients` – связь врачей и пациентов
- `DiagnosisView` – справочник диагнозов (обновляемое)

**Функции (UDF)**

- `CalculatePatientBill` – сумма счёта по процедурам
- `CalculatePatientBillByStayDuration` – стоимость пребывания в палате
- `CheckRoomAvailability` – проверка свободных мест в палате
- `GetPatientsByAdmissionPeriod` – отбор пациентов по периоду госпитализации

**Хранимые процедуры**

- `AddNewPatient` – добавление пациента с автоматическим подбором палаты
- `DischargePatient` – выписка с обновлением даты и освобождением места
- `UpdateMedicalHistory` – изменение диагноза, врача, плана лечения
- `AddNewProcedure` – добавление процедуры с проверкой дубликатов
- `InsertIntoDiagnosisView` – вставка новых диагнозов через представление

**Триггеры**

- `trg_UpdateWardAvailability` – обновление занятости палаты при поступлении
- `trg_DischargePatient` – освобождение места при выписке
- `trg_AddMedicalHistory` – автоматическое создание медкарты при поступлении
- `trg_AfterDischargeDateUpdate` – формирование счёта за пребывание
- `trg_AfterDischargeUpdateBillProcedures` – формирование счёта за процедуры

### Технологии

- **СУБД:** Microsoft SQL Server
- **Язык:** T-SQL
- **Проектирование:** ERD, нормализация (3NF)
